# Предвыборный опрос в Гагаузии 2026 — настройка

Файлы:
- `index.html` — сам опрос (один файл, без зависимостей). Публикуется через GitHub Pages.
- `Code.gs` — бэкенд на Google Apps Script, пишет ответы в Google Sheet.

## 1. Google Sheet + Apps Script (5 минут)

1. Создайте новую Google Таблицу (например, `Gagauzia 2026 — responses`).
2. В ней: **Расширения → Apps Script**. Удалите содержимое `Code.gs` и вставьте код из файла `Code.gs`. Сохраните (Ctrl+S).
3. **Развернуть → Новое развёртывание** → тип **Веб-приложение**:
   - Описание: `survey`
   - Выполнять от имени: **Я (ваш аккаунт)**
   - У кого есть доступ: **Все** (Anyone) — обязательно, иначе анонимные респонденты не смогут отправлять ответы.
4. Нажмите **Развернуть**, разрешите доступ (Advanced → Go to project → Allow).
5. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. В `index.html` замените строку
   `const ENDPOINT = "PASTE_APPS_SCRIPT_WEB_APP_URL_HERE";`
   на ваш URL.

Проверка: откройте URL `/exec` в браузере — должно вернуться `{"ok":true,"service":"gagauzia2026"}`.

Если позже меняете код скрипта — **Развернуть → Управление развёртываниями → ✎ → Версия: новая → Развернуть** (URL останется тем же).

## 2. GitHub Pages и адрес страницы

1. Репозиторий (например `watchdog-md/gagauzia2026`): положите в корень все файлы из архива (`index.html`, `og.png`, `favicon.svg`, `apple-touch-icon.png`, папку `share/` можно не публиковать).
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main` / `/ (root)` → Save.
3. Через 1–2 минуты страница доступна по адресу `https://<org>.github.io/gagauzia2026/`.
4. **Один раз** замените в `index.html` адрес `https://example.github.io/gagauzia2026/` на реальный (Ctrl+H, 6 вхождений) — он нужен Facebook/Telegram, чтобы показать картинку и заголовок при распространении ссылки. Можно привязать свой домен (Settings → Pages → Custom domain + CNAME у регистратора) — тогда укажите его.
5. Проверка превью: https://developers.facebook.com/tools/debug/ → вставьте ссылку → «Scrape again». В Telegram: отправьте ссылку боту @WebpageBot, чтобы обновить кэш.

## 3. Ссылки по источникам

Добавляйте `?src=` к ссылке, чтобы видеть, откуда пришёл респондент (столбец `collector`):
- `…/?src=fb` — Facebook
- `…/?src=tg` — Telegram
- `…/?src=viber`, `…/?src=ok`, `…/?src=site` и т.д.

## 4. Как устроены данные (лист `responses`)

Одна строка = один респондент (`respondent_id` — случайный анонимный ID, хранится в браузере респондента).
- `status`: `partial` / `complete`; `last_page`: последняя пройденная страница (1–5).
- Строка **обновляется** после каждого нажатия «Далее» и при закрытии вкладки, поэтому ответы прервавших опрос тоже сохраняются.
- `Q1 | <вариант>` — отдельный столбец на каждый вариант (как в экспорте SurveyMonkey): содержит текст варианта, если выбран, иначе пусто.
- `Q9 | Округ №` — номер округа (1–35), определяется автоматически для сёл с одним округом.
- `Q10` — кандидат, `Q10 | Партия` — его выдвижение.
- `Q11 | <государство>` — ответ по каждой строке матрицы.
- `Q1 | порядок` — случайный порядок показа вариантов Q1 (индексы), для контроля эффекта порядка.

Тестовые ответы можно удалять прямо в таблице. Для повторного прохождения опроса на том же устройстве откройте ссылку с `?reset=1`.

## 5. Ограничения

- Apps Script: ~20 000 вызовов в день на аккаунт (у каждого респондента ~5–6 вызовов) — достаточно для нескольких тысяч ответов в день.
- Один человек может пройти опрос повторно, очистив данные браузера или с другого устройства (как и в SurveyMonkey). Для анализа можно отфильтровать дубликаты по времени/ответам.

- `og.png` (1200×630) — превью ссылки в Facebook, Telegram, Viber, WhatsApp, X; лежит в корне рядом с `index.html` (см. п. 2.4 про адрес).
